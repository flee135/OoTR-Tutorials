# OoTR Tutorials

A collection of Ocarina of Time Randomizer tutorials

The site is built with [MkDocs](https://www.mkdocs.org/) using the [Material](https://squidfunk.github.io/mkdocs-material/) theme.

## Building locally

### Prerequisites

- [Python](https://www.python.org/) 3.x

### Install dependencies

These are the same packages the deploy workflow uses:

```bash
pip install mkdocs-material mkdocs-git-revision-date-localized-plugin
```

### Preview with live reload

```bash
mkdocs serve --livereload
```

Then open <http://127.0.0.1:8000/>. Edits to the docs hot-reload in the browser.
