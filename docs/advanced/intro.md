# Advanced Tutorials

You're now comfortable enough to complete any seed, and have perhaps participated in some races. The goal of these tutorials is to try to put up even more competitive times, aiming to make it past qualifying stages for tournaments, or move up in League divisions.

Keep in mind that these tutorials can sometimes be more subjective than intermediate ones, and different players might have different opinions on some of these topics, so keep an open mind and treat some of the advice here as just my opinion.

The advanced tutorials go into the following:

- [General Advice](./general.md)
- Logic
- Execution
