# Zora's River

## Important

- (Child) You can enter domain using a [cucco](https://www.youtube.com/watch?v=1juo8sED_Go). A setup isn't needed, as long as Link touches the wall before the waterfall, he should be able to slide behind it and into the entrance. You can also do this jump from the [right side](https://www.youtube.com/watch?v=TRYxabMb4VY), which is faster but also riskier.

- (Adult) You can enter domain using [hovers](https://www.youtube.com/watch?v=jdSZDAUEzz4). Instead of ESS turns, you can aim for the white stripe with c up or a first person item. The exact position is not precise.

- (Adult) You can jump to the freestanding items without any items ([lower](https://www.youtube.com/watch?v=pWeKUymMHWY), [upper](https://www.youtube.com/watch?v=FXxvf0IgmhQ)).

- (Child) To grab the bottom freestanding item, you can either jump from above with a cucco. From below, you can jump to the ledge with a cucco, but you need to let go of the cucco to grab the ledge.
